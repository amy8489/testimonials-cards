# Testimonial Cards

A set of testimonial cards for a website, built with HTML and CSS only — no JavaScript. Three different layouts: a black speech-bubble card, a white bordered card, and a large centered carousel-style card.

## Files
- `index.html` — Testimonial cards page with 3 cards
- `styles.css` — Layout, positioning, and responsive styles

## How to run it
Double-click `index.html` to open it in your browser, or view the live site below.
